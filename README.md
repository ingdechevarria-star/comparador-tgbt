# Comparar precios TGBT — CPK Ingeniería

Comparador autónomo para GitHub Pages. `index.html` incluye los datos y recursos necesarios para funcionar: **5 proveedores, 146 grupos de componentes, 310 renglones, 10 presupuestos originales y 24 páginas de evidencia**.

El archivo `.nojekyll` desactiva el procesamiento de Jekyll y permite publicar directamente este HTML.

## Publicar paso a paso

1. Descargá el ZIP y **extraé todos sus archivos**.
2. Abrí tu repositorio en GitHub y seleccioná la rama **main**.
3. Elegí **Add file → Upload files**. Subí `index.html`, `.nojekyll` y `README.md` directamente a la raíz del repositorio.
4. Completá la carga con **Commit changes**, en la rama **main**.
5. Entrá en **Settings → Pages**.
6. En **Source**, seleccioná **Deploy from a branch**.
7. En **Branch**, elegí **main** y **/(root)**. Pulsá **Save**.
8. La publicación puede tardar hasta **10 minutos**. Volvé a **Settings → Pages** y abrí **Visit site** para usar el comparador.

Abrir `index.html` dentro del repositorio muestra su código. **Visit site** abre la aplicación publicada.

## Alcance de la publicación

El sitio público permite consultar y descargar los **presupuestos originales**, junto con sus datos comerciales. Publicalo con ese alcance presente.

La conversión base utiliza **BNA dólar billete vendedor: ARS 1.540 por USD**, publicado el **06/10/2026 a las 17:00**. Es una referencia guardada: **no actualiza automáticamente el dólar ni los presupuestos**. El campo de tipo de cambio permite comparar escenarios.
